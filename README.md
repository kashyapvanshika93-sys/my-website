# 💻 Computer House

### Building Digital Skills, Smart Minds & Future-Ready Professionals

Computer House is a responsive computer education and service center website developed using **HTML, CSS, and JavaScript**. It presents computer training programs, technical services, a gallery, and a contact section through a clean and modern interface.

## 🌐 Website Preview

The website features a blue-themed design, a full-screen hero section, interactive navigation, service cards, and a responsive image gallery.

## ✨ Features

- **Home:** Attractive hero section with a background image and welcome message.
- **About Us:** Introduction to Computer House and its educational mission.
- **Our Services:** Information about computer education, programming, hardware repair, software support, networking, and project guidance.
- **Gallery:** Image gallery showcasing programming labs, students learning, hands-on practice, and technology.
- **Contact Us:** Contact form with name, email, and message fields.
- **Responsive Layout:** Flexible CSS grid layouts that adapt to different screen sizes.
- **Interactive Navigation:** Navigation links for quick access to website sections.
- **Hover Effects:** Smooth visual effects on service cards and navigation links.
- **Form Validation:** Required fields and email input validation using HTML.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layouts, gradients, cards, and hover effects |
| JavaScript | Contact form interaction and alert messages |
| Unsplash | Background and gallery images |

## 📌 Website Sections

### 1. Home
Introduces Computer House with a large background image and the tagline *Building Digital Skills, Smart Minds & Future-Ready Professionals*.

### 2. About Us
Explains the center's focus on digital literacy, practical computer education, technical skills, and student development.

### 3. Our Services
The website showcases six services:

- Computer Education
- Programming
- Hardware Repair
- Software Support
- Networking
- Project Guidance

### 4. Gallery
Displays images related to programming, collaborative learning, practical training, mobile technology, and modern technology environments.

### 5. Contact Us
Provides a form where visitors can enter their name, email address, and message.

**Note:** The current contact form displays a confirmation alert but does not actually send or store messages. Backend integration is required for real submissions.
